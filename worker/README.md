# AnuRAG worker

The API behind the chat on the portfolio. GitHub Pages can't hide an API key, so this Cloudflare Worker holds it.

```
browser -> worker: origin check -> rate limit -> BM25 over knowledge.json -> Gemini -> guard -> browser
```

- `src/knowledge.json` is generated by `python3 src/build.py` from `src/content.py` and the approved repo docs listed in
  `src/knowledge.py` (never the interview guides). Don't edit it by hand, and redeploy the worker after either changes.
- `GEMINI_MODELS` is tried in order, because each model has its own free daily quota (20 requests each in Nov 2026), then
  Cloudflare Workers AI. When all are out, visitors get a "give me a minute" line. `npx wrangler tail` shows failures.
- `src/guard.js` withholds a reply unless every claim cites a passage and every number is in the passage it cites.
  It can't catch a false claim with no number in it; the system prompt and the citations carry that.
- Questions with no matching passage, and greetings, never reach the model, so they cost no quota.

## Deploy

Use a Gemini key from a project with no billing attached, so the worst case is hitting the free limit, not a bill.

```bash
npm install
npx wrangler login
npx wrangler secret put GEMINI_API_KEY
npx wrangler deploy
```

Then put the deployed URL plus `/chat` in `ASSISTANT["endpoint"]` in `src/content.py` and run `python3 src/build.py`.
The chat stays hidden on the site until that value is set.

## Test

`npm test` needs no key. To run it locally, create a gitignored `.dev.vars` with `ALLOWED_ORIGINS`, `GEMINI_BASE`
and `GEMINI_API_KEY`, then `npm run dev`. To preview the chat, build the site with
`ANURAG_ENDPOINT=http://localhost:8787/chat python3 src/build.py`, and rebuild without it before committing.
