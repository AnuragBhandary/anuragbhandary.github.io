# AnuRAG worker

The API behind the chat on the portfolio. GitHub Pages can't hide an API key, so this Cloudflare Worker holds it.

```
browser -> worker: origin check -> rate limit -> BM25 over knowledge.json -> Gemini / Groq -> guard -> browser
```

- `src/knowledge.json` is generated by `python3 src/build.py` from `src/content.py` and the approved repo docs listed in
  `src/knowledge.py`. Don't edit it by hand, and redeploy the worker after either changes.
- `MODELS` is tried in order, because each model has its own free daily quota (about 20 requests each for Gemini in
  Nov 2026; Groq's gpt-oss-120b allows 200K tokens a day, about 70 answers). Names starting `groq/` go to Groq, the
  rest to Gemini, then Cloudflare Workers AI.
- A project page sends its slug, so vague questions there ("what were the results?") are about that project.
- "List his projects" gets a fixed grouped answer built in `src/knowledge.py`, without a model call. When all are out, visitors get a "give me a minute" line. `npx wrangler tail` shows failures.
- `src/guard.js` drops any sentence whose number isn't in the passage it cites, and withholds the reply if half or more
  fail or nothing is cited.
  It can't catch a false claim with no number in it; the system prompt and the citations carry that.
- Questions with no matching passage, and greetings, never reach the model, so they cost no quota.

## Deploy

Use Gemini and Groq keys with no billing attached, so the worst case is hitting the free limit, not a bill.

```bash
npm install
npx wrangler login
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put GROQ_API_KEY
npx wrangler deploy
```

Then put the deployed URL plus `/chat` in `ASSISTANT["endpoint"]` in `src/content.py` and run `python3 src/build.py`.
The chat stays hidden on the site until that value is set.

## Test

`npm test` needs no key. To run it locally, create a gitignored `.dev.vars` with `ALLOWED_ORIGINS`, `GEMINI_BASE`
and `GEMINI_API_KEY`, then `npm run dev`. To preview the chat, build the site with
`ANURAG_ENDPOINT=http://localhost:8787/chat python3 src/build.py`, and rebuild without it before committing.
